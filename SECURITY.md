# セキュリティ方針 / Security Policy

## 脆弱性を見つけたら（日本語）

micro-monban はセキュリティのための装置です。弱点が公開の場に先に出ると、使っている人が狙われます。
**Issue や Pull Request など公開の場には書かず**、次の方法で非公開でお知らせください。

1. このリポジトリの **Security** タブ →「**Report a vulnerability**」から報告してください（GitHub の非公開報告機能）。
2. 次の内容があると助かります。
   - 影響を受ける版（例: v1.12.0）
   - 再現手順（どんな要求を送ると、何が起きるか）
   - 想定される影響（すり抜け、情報漏えい、停止など）
3. 報告は日本語でも英語でも構いません。

個人で運営しているため、返信や修正に時間がかかることがあります。修正が出るまでは公表を控えてください。

### 対象
- `src/`・`install/`・`tools/` のコードと、導入スクリプトが作る設定（nginx・nftables・systemd）

### 対象外
- Raspberry Pi OS・nginx・Python など、他のプロジェクトそのものの脆弱性（それぞれの提供元へ）
- 利用者が独自に変更した設定や、マニュアルの推奨に反した運用で起きた問題

## Reporting a vulnerability (English)

micro-monban is a security appliance. Publicly disclosed weaknesses put its users at risk.
**Please do not open a public issue or pull request.** Report privately instead:

1. Open the **Security** tab of this repository and click **"Report a vulnerability"** (GitHub private vulnerability reporting).
2. Please include:
   - Affected version (e.g. v1.12.0)
   - Steps to reproduce (what request causes what behavior)
   - Expected impact (bypass, data leak, denial of service, etc.)
3. Reports in English or Japanese are welcome.

This project is maintained by an individual, so responses and fixes may take some time. Please keep the issue confidential until a fix is released.

### In scope
- Code in `src/`, `install/`, `tools/`, and the configuration generated by the installer (nginx, nftables, systemd)

### Out of scope
- Vulnerabilities in third-party projects such as Raspberry Pi OS, nginx, or Python (please report to those projects)
- Problems caused by user modifications or by operation contrary to the documentation

| --- | --- |
| 最新版 / latest | ✅ |
| それ以前 / older | ❌（最新版へ更新してください / please upgrade） |
