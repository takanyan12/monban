# サーバー役PCの設定

サーバー役PC は、門番の内側（閉域 10.0.0.0/24）に有線1本でつなぎ、**門番（10.0.0.1）からだけ**接続を受けるようにします。

## 共通の約束

| 項目 | あるべき状態 |
| --- | --- |
| 有線アダプター | IP `10.0.0.2` / `255.255.255.0`、**ゲートウェイと DNS は空欄** |
| Wi-Fi | **止める**（入れると門番を通らない道ができる） |
| Web アプリ | `10.0.0.2:8080` で待ち受ける（`localhost` だけだと門番から届かない） |
| ファイアウォール | Web アプリ（8080）などは **10.0.0.1 からだけ**許可 |

## Windows

### かんたん設定（バッチ）

`backend/setup-windows.bat` を右クリック →「**管理者として実行**」。次のことを行います。

1. 今のネットワーク設定をデスクトップに控える
2. ファイアウォール: 門番（10.0.0.1）からだけ 8080・11434 番と ping を許可。PHP や Ollama を初めて起動したときに自動で作られる「誰からでも許可」ルールは無効化
3. 有線アダプターを 10.0.0.2 に（確認あり）
4. Ollama を 10.0.0.2 だけで待ち受けさせる（任意）
5. 門番との疎通テスト

> このバッチは文字コード CP932・改行 CRLF で保存されています。エディタで文字コードを変えて保存しないでください。

### PHP を動かす例

1. php.net の Windows 版（**VS17 x64 Non Thread Safe** の ZIP）を `C:\PHP` に展開
2. `C:\PHP\php.ini-development` を `C:\PHP\php.ini` にコピーし、必要な拡張（`extension=mbstring` など）の `;` を外す。`date.timezone = Asia/Tokyo`
3. 公開するフォルダ `C:\PHP\www` を作る
4. 起動（そのウィンドウを開いている間だけ動きます）:
   ```bat
   C:\PHP\php.exe -S 10.0.0.2:8080 -t C:\PHP\www
   ```

> `php -S` は開発用の簡易サーバーです。本番では Apache や nginx + PHP-FPM などをおすすめします。

**見本のページ**: `backend/demo-site/index.php` は、門番の紹介と「試してみる」（わざと攻撃に見える要求を送り、門番が止める様子を見せる）を載せた1枚のページです。`C:\PHP\www\index.php` として置けば、デモにそのまま使えます。外部の画像やフォントは使いません。
試験用のページ（個人情報や秘密情報の見本を返すもの）は、**インターネットに公開する前に公開フォルダーから外してください**。

### Ollama を使う場合

1. ユーザー環境変数 `OLLAMA_HOST` を `10.0.0.2:11434` にする（バッチの手順4でも設定できます）
2. Ollama の Settings で「**Expose Ollama to the network**」を **OFF**（ON だと `OLLAMA_HOST` より優先され、すべてのアドレスで待ち受けてしまう）
3. タスクトレイから Ollama を終了して起動し直す
4. `%LOCALAPPDATA%\Ollama\server.log` に `Listening on 10.0.0.2:11434` と出れば OK

### 確認

門番（Pi）の上で:
```bash
curl -s -o /dev/null -w '%{http_code}\n' http://10.0.0.2:8080/      # 200 など
curl -s http://10.0.0.2:11434/api/version                            # Ollama を使う場合
```
- **時間切れ（タイムアウト）** → Windows のファイアウォールで止められています
- **すぐに接続拒否** → アプリが動いていないか、`localhost` だけで待ち受けています

### PHP・Ollama を更新したとき

更新すると「アクセスを許可しますか」がまた出て、「誰からでも許可」のルールが作られることがあります。バッチをもう一度実行してください。

## Linux（実験的）

`backend/setup-backend-linux.sh` は**理論上の設計で未検証**です。内容を読んで理解したうえでお使いください。
考え方は Windows と同じで、10.0.0.2 の固定、ゲートウェイなし、ファイアウォールで 10.0.0.1 からだけ許可、アプリは 10.0.0.2 で待ち受けます。
