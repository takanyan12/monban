# 本体画面（HDMI タッチモニター）

Raspberry Pi 5 の HDMI にモニター（できればタッチ付き）をつなぐと、門番の状態と設定を**本体の画面で見て操作できます**。PC や SSH が無くてもメンテナンスでき、ネットワークの設定を間違えて SSH がつながらなくなったときも、その場で直せます。

> v1.13.0 から。デスクトップ付きの Raspberry Pi OS が必要です。

## 画面は2つ

| 画面 | 中身 | パスワード |
| --- | --- | --- |
| **ダッシュボード** | 守りの状態（緑・黄・赤）、今日のアクセス数と拒否数、遮断中の IP の数、個人情報ガードの件数、部品の状態、最近のできごと、Wi-Fi・IP | 不要（見るだけ） |
| **設定** | 初期設定（案内付き）、Wi-Fi、守りのスイッチ、遮断の解除、メール通知、パスワード、ネットワーク（確認）、自己試験、時刻・再起動 | 必要 |

- 設定は **5 分触らないと自動でロック**され、ダッシュボードに戻ります。右上の「ロック」ですぐにロックすることもできます。
- パスワードを **5 回続けて間違えると 60 秒間受け付けません**。
- 文字は**画面のキーボード**で入力します（物理キーボードも使えます）。「次の欄」で次の入力欄へ、「決定」でその画面の青いボタンを押します。

## 初期パスワード

- 導入スクリプトが、機器ごとに違う**初期パスワード**を作り、導入の最後に **1回だけ**表示します。管理画面と本体画面の共通のパスワードです。
- 本体画面で初期パスワードを使って開くと、**新しいパスワードを決めるまで、ほかの設定には進めません**。決めたあとは初期設定の案内（Wi-Fi → メール通知 → サーバー役PC → 自己試験）に進みます。
- 新しいパスワードは 10 文字以上。英数字と記号が使えます（引用符・バックスラッシュ（円記号）・$・バッククォート・#・空白は使えません）。変えると管理画面のパスワードも同じものに変わります。
- 忘れたときは、本体画面のパスワード入力の「忘れたとき」か、説明書の[困ったとき → パスワードを忘れたとき](troubleshooting.md#パスワードを忘れたとき)へ。SSH に入れるなら `sudo bash install/setup-gatekeeper.sh --reset-password` で初期パスワードを作り直せます。

## モニターに出す

導入スクリプト（v1.13.0 以降）を実行したあと、モニターに出す設定をします。

```bash
sudo bash tools/setup-kiosk.sh
```

- Chromium と日本語フォント（`fonts-noto-cjk`）が無ければ導入します。
- ログインしたら全画面で本体画面が開くようにします（Chromium のキオスク表示）。
- 「電源を入れたら自動でデスクトップにログインするか」を聞かれます。モニターで使うなら `yes` が便利です。
- 終わったら `sudo reboot`。

やめるとき:
```bash
sudo bash tools/setup-kiosk.sh --remove
```

### 必要なもの
- HDMI モニター（7 インチ・800×480 程度のタッチ付きがおすすめ。大きいモニターでも表示は合わせて大きくなります）
- Raspberry Pi 5 は **micro HDMI** なので、変換ケーブルかアダプター
- タッチを使うなら、タッチ信号用の USB ケーブル

## Wi-Fi の切り替えと「60 秒の確認」

- 設定 → Wi-Fi で近くの Wi-Fi を一覧から選び、パスワードを入れて接続します。
- 接続したあと **60 秒以内に「このまま使う」を押さないと、元の Wi-Fi に自動で戻ります**。間違えても締め出されません。
- 家庭 LAN の範囲（例: 192.168.1.0/24）が違う場所へ移すときは、導入スクリプトの設定ブロック（`HOME_NET` など）も合わせて実行し直してください（画面からの変更は今後の版で対応します）。

## 安全について

- 本体画面のサーバー（`gatekeeper-kiosk`）は **127.0.0.1:9100 だけで待ち受け**ます。家庭 LAN やインターネットからは見えません。
- よその名前（Host）での読み取り、専用ヘッダの無い操作、パスワード無しの操作は拒否します（自己試験で確かめられます）。
- **その場にいる人は画面を見られます。** ダッシュボードには遮断中の IP などが出ます。人目に触れる場所では、モニターの置き場所に気をつけてください。
- 自動ログインしたデスクトップの上で全画面表示しているので、**キーボードをつないだままにすると、キー操作で全画面を抜けられる**ことがあります。ふだんはタッチだけにして、キーボードは外しておくのがおすすめです。
- Wi-Fi のパスワードは、接続の数秒間だけ `nmcli` の引数として本体内に見えます（本体にログインできる人だけ）。

## できないこと（今後の版で予定）
- 家庭 LAN の範囲・内側 IP・サーバー役PC の IP とポートの画面からの変更（いまは表示と接続確認のみ）
- デスクトップの無い Raspberry Pi OS Lite での表示
- 画面の明るさ・消灯時間の設定
