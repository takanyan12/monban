# 運用ガイド（管理画面の使い方）

管理画面は `https://10.0.0.1:9000/`（閉域側）か、SSH の転送経由の `https://localhost:9000/` で開きます（[導入ガイド](install.md#7-管理画面を開く)）。
各カードの見出しにある「？」を押すと、画面の中でも説明が読めます。

## 毎日〜毎週見るところ

| 見るところ | 正常 | 気にすること |
| --- | --- | --- |
| 上部の緊急バナー | 出ていない | 出ていたら内容を読み、誤検知なら「誤検知として解除」 |
| セルフ整合性監視 | ✓ 正常 | 「重大（改竄の疑い）」は心当たりがなければ緊急ブレーカーを検討 |
| 個人情報 一括持ち出しガード | ON（超えたら遮断） | 遮断の履歴に、本当の利用者が出ていないか |
| 設定レポート | 毎週メールで届く | 冒頭の「要確認の項目」 |

## 各カード

### 外部側 管理アクセス（スイッチ）
家庭 LAN 側から管理画面（9000番）に入れるようにする一時的なスイッチです。ふだんは**停止**のままにし、SSH の転送で管理するのがおすすめです。開けている間は HTTPS とパスワード（ユーザー名 `admin`）で守られます。
スイッチの状態は保存され、再起動やファイアウォールの再読み込みのあとも元に戻ります。

### 許可リスト／AI 動的遮断リスト
- **許可リスト**: 登録した IP は自動遮断の対象外になります。管理に使う PC を入れておくと、試験のときなどに自分が締め出される心配がありません。
- **動的遮断リスト**: 怪しい振る舞い（点数80以上、SSH の失敗5回/5分、1時間の低速スキャン）で自動遮断された IP。10分で自動解除されます。「許可リストへ移動」「単に解除」もできます。
- Cloudflare Tunnel 経由のアクセスにも効くよう、遮断した IP は nginx 側でも拒否されます（15秒ごとに同期）。

### DLP 機密マスキング ルール
サーバーの応答に含まれる機密を伏せ字にするルールです。初期は15種（11種が ON）。
- メールアドレス・カード番号・マイナンバー様式・内部 IP は、誤検知で画面が崩れやすいため初期は OFF です。
- 「マスキング試験」に文章を貼ると、どう伏せ字になるかを確かめられます。
- ルールの追加では、シングルクォート `'`、`;`、改行は使えません。

### セルフ整合性監視
重要ファイルの指紋（sha256）、門番からの予定外の外向き通信、予定外の待ち受けポートを5分ごとに点検します。
設定を手で変えたときは、台帳を作り直してください（`sudo GK_REBUILD_MANIFEST=1 python3 /opt/gatekeeper/dashboard.py`）。導入・更新のスクリプトは自動で作り直します。

### 出口防御 & 緊急ブレーカー
- **出口防御**: 大量のデータ送信（1回 50MB／10分 100MB）、5xx エラーの連発、監視パスへの個人情報の連続取得を検知して警報を出します。初期設定は「通報のみ」です。
- **緊急ブレーカー**: 「外部入口を遮断」で外からの通信をすべて止め、「バックエンドと分離」でサーバー役PC を切り離します。「復旧」で元に戻ります。
- **メール通知**: SMTP と宛先を設定すると、警報がメールで届きます。Gmail ならアプリ パスワードを使い、`smtp.gmail.com`・ポート `587` です。

### 個人情報 一括持ち出しガード
サーバーの応答に含まれる個人情報（メール・電話・カード番号・マイナンバー・住所）を数え、**数件までは通し、それを超える一括送信を止めます**（403）。
- 初期値: 1回の応答で **5件まで**、同じ接続元へ **10分で30件まで**
- 「止めずに記録だけする」にすると、止めずに履歴だけ残せます（導入直後の様子見に）
- 数え方は推定です。名前だけの一覧などは数えられません。逆に、12桁の業務 ID が偶然マイナンバーと判定されることがあります
- このガードは nginx とサーバー役PC の間で動いています。**止まると Web 全体が 502 になります**（自動で再起動します）

### 設定レポート（引き継ぎ用）
門番の今の状態（版・サービス・ネットワーク・整合性・各ガード・ルール・警報・バックアップの一覧）を1つの文書にまとめ、メールで送ります。冒頭に「異常の見分け方と最初の一手」が入るので、詳しくない人にも渡せます。
- 送るタイミング: 毎週（曜日・時刻を指定）、設定が変わったとき、「今すぐ送信」
- パスワード・鍵・メール認証情報は含みません
- メール通知が未設定でも、Pi の `/var/lib/gatekeeper/reports` に保存されます。「ファイルに保存」で手元にも取れます

### インターネット公開
[インターネット公開](publish.md) を見てください。

### AI 振る舞い分析（脅威レーダー）
接続元ごとに、アクセス間隔の規則性・エラー率・パスのばらつきから点数を付けます。80点以上で自動遮断します。

## 定期的にすること

| 頻度 | すること |
| --- | --- |
| 毎週 | 設定レポートを読む |
| 毎月 | `sudo apt update && sudo apt upgrade` で OS とソフトを更新（そのあと `--verify`） |
| 3か月ごと | `sudo bash tools/gk_check.sh` で健康診断。バックアップ（`/opt/gatekeeper/backup_*`）の整理 |
| 2年ごと | 門番の自己署名証明書の期限（825日）。期限が近づいたら証明書を作り直す |
